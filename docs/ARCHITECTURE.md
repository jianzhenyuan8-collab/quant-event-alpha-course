# 自动市场事件与Alpha研究系统架构（教学蓝图）

```text
历史OHLCV / 逐笔成交 / OI / 资金费率
                 |
          数据质量与时间对齐
                 |
    特征工厂（历史已完成K线）
                 |
    +------------+------------+
    |                         |
无监督形态发现             监督式因子研究
    |                         |
    +------------+------------+
                 |
          候选事件/因子库
                 |
      训练、验证、滚动样本外
                 |
       基准对照 + 多重检验
                 |
        研究报告和准入审查
                 |
      纸面执行 / 模拟账户
                 |
       经授权的风险控制层
                 |
      交易所API或链上协议
```

设计原则：研究与资金执行权限隔离；默认没有资金控制能力。发现阶段可以频繁探索，但不能反复在最终测试集挑最好结果。每个候选要保存数据来源、参数、规则代码、训练时间和所有失败实验。

## 多时间尺度

优先保存5M基础K线，按UTC规则聚合得到15M/30M/2H/6H/1D，所有高周期特征只有在该周期结束后才可作为5M决策的输入。5D不一定是原生交易所K线周期，使用时明确聚合锚点。高精度市场轮廓需要逐价位成交，不能把5M HLC3近似当成真实量价分布。

## 回测

采用按时间分段或滚动窗口，对连续事件窗口去重、分组或用合适的时间块方法评估有效样本。根据完整路径判断止盈/止损触及次序；同根K线双触及时用更细数据或保守处理。单独模拟费用、滑点、资金费率、维持保证金及标记价格强平。

## 执行隔离

模拟订单状态：Created、Submitted、PartiallyFilled、Filled、Cancelled、Rejected。相同信号的唯一ID不得重复执行；执行失败不应被误判成交；紧急暂停和仓位对账必须优先于策略信号。Reactive适用于支持的链上事件和回调，不等于直接访问中心化交易所API。
