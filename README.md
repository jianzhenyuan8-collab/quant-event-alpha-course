# 从零理解量化研究：市场事件、Alpha 与机器学习（60章）

这是一套面向具有高中数学基础的学习者的中文量化研究课程，从复利、概率与风险开始，逐步学习多时间尺度市场事件、因子研究、Alpha、机器学习、统计验证、动态决策与事件驱动交易系统。

本项目为**研究和教育用途**，不提供自动实盘下单功能。教学示例使用合成数据，不代表真实 BTC 历史回测结果。

课程文件与可运行实践实验正在导入本仓库。

## 学习路径

- 第1—12章：概率、复利、期望和交易风险
- 第13—20章：市场事件与多时间尺度
- 第21—33章：历史数据、事件统计与价格路径
- 第34—40章：机器学习与自动事件发现
- 第41—49章：量化因子、Alpha 和概率预测
- 第50—53章：交易决策、贝叶斯更新和状态机
- 第54—60章：自动 Alpha 研究、验证与执行系统

> 请勿将教学数据与模拟结果当作投资依据。
